# kiln_cli

The Kiln command line interface.

```bash
kiln create my_app --with dio --answer base_url=https://api.example.com
kiln create starter_app --template app
kiln add dio
kiln doctor
kiln remove dio --yes
```

Commands and exit codes are described in
[docs/cli/reference.md](../../docs/cli/reference.md).

The brick bundles and extension manifests in `lib/src/bundles/` are generated by
`tool/bundle.dart`; do not edit them by hand.

# Lokalisasi

Extension `l10n` mengisi titik sambung `AppLocalizationsConfig` milik
`app_basic`. Setelah terpasang, `AppShell` memakai delegate hasil gen-l10n,
daftar locale, dan locale aktif dari extension ini tanpa perubahan kode
aplikasi.

## Sumber terjemahan

```text
l10n.yaml                 # konfigurasi flutter gen-l10n
lib/l10n/
├─ app_en.arb             # template dan terjemahan Inggris
├─ app_id.arb             # terjemahan Indonesia
└─ generated/             # AppLocalizations hasil generate (tidak diedit)
```

`app_en.arb` adalah template: key dan metadata placeholder/plural didefinisikan
di sana. Setiap bahasa lain wajib memiliki key yang sama.

## Komponen

| Tipe | Fungsi |
| --- | --- |
| `AppLocalizations` | Kelas hasil gen-l10n dengan getter per key ARB. |
| `L10nConfig` | Daftar locale yang didukung dan locale cadangan. |
| `LocaleResolution` | Memetakan locale perangkat ke locale yang didukung. |
| `LocaleController` | Menyimpan locale aktif; `null` berarti ikut sistem. |
| `LocaleStore` | Menyimpan pilihan locale lewat `Storage`. |
| `LanguageSwitcher` | Widget pemilih bahasa. |
| `L10nFailureMessages` | Pesan ramah untuk setiap `FailureCode` dari ARB. |

## Locale aktif

`LocaleController` memiliki `ValueNotifier<Locale?>`. Nilai `null` berarti
aplikasi mengikuti locale perangkat. `AppLocalizationsConfig` menerima
`localeListenable`, sehingga memilih bahasa langsung membangun ulang
`MaterialApp`.

```dart
final controller = registry.read<LocaleController>();

await controller.setLocale(const Locale('en'));
await controller.followSystem(); // kembali ke locale perangkat
```

Pilihan disimpan dengan key `kiln.l10n.locale` bila `Storage` tersedia. Tanpa
`storage`, pilihan hanya berlaku sampai aplikasi ditutup. `load()` dipanggil
saat modul siap dan bersifat best effort.

## String

```dart
final l10n = AppLocalizations.of(context);

Text(l10n.appTitle);
Text(l10n.retry);
Text(l10n.helloName('Ana'));
Text(l10n.itemsCount(3));
```

- `AppLocalizations.of(context)` tidak nullable; delegate selalu terpasang
  lewat `AppLocalizationsConfig`.
- Placeholder dan plural ditangani gen-l10n/intl, bukan formatter sendiri.
- Setelah mengubah ARB, jalankan `flutter gen-l10n` atau `flutter pub get`.

## Pesan kegagalan

`L10nFailureMessages` mengimplementasikan `FailureMessages` dari `app_basic`.
Modul mendaftarkannya ke `Registry`, jadi `FailurePresenter.fromRegistry`
otomatis memakai teks sesuai locale aktif. Kode yang belum dikenal memakai
`failureUnexpected`.

## Pemilih bahasa

```dart
LanguageSwitcher(
  controller: registry.read<LocaleController>(),
  config: registry.read<L10nConfig>(),
);
```

Gunakan `style: LanguageSwitcherStyle.segmented` untuk tampilan segmen.
Daftar bahasa berasal dari `supportedLocales`, bukan hardcode di widget.

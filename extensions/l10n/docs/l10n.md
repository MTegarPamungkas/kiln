# Localization

The `l10n` extension fills the `AppLocalizationsConfig` seam owned by
`app_basic`. Once installed, `AppShell` uses the gen-l10n delegates, the locale
list, and the active locale from this extension without app code changes.

## Translation sources

```text
l10n.yaml                 # flutter gen-l10n configuration
lib/l10n/
├─ app_en.arb             # English template and translations
├─ app_id.arb             # Indonesian translations
└─ generated/             # generated AppLocalizations (not edited)
```

`app_en.arb` is the template: keys and placeholder/plural metadata are defined
there. Every other language must have the same keys.

## Components

| Type | Function |
| --- | --- |
| `AppLocalizations` | Class generated by gen-l10n with a getter per ARB key. |
| `L10nConfig` | List of supported locales and the fallback locale. |
| `LocaleResolution` | Maps the device locale to a supported locale. |
| `LocaleController` | Stores the active locale; `null` means follow the system. |
| `LocaleStore` | Persists the locale choice through `Storage`. |
| `LanguageSwitcher` | Language picker widget. |
| `L10nFailureMessages` | Friendly message for each `FailureCode` from ARB. |

## Active locale

`LocaleController` has a `ValueNotifier<Locale?>`. A `null` value means the app
follows the device locale. `AppLocalizationsConfig` accepts
`localeListenable`, so choosing a language immediately rebuilds `MaterialApp`.

```dart
final controller = registry.read<LocaleController>();

await controller.setLocale(const Locale('en'));
await controller.followSystem(); // return to the device locale
```

The choice is stored under the key `kiln.l10n.locale` when `Storage` is
available. Without `storage`, the choice only lasts until the app is closed.
`load()` is called when the module is ready and is best effort.

## Strings

```dart
final l10n = AppLocalizations.of(context);

Text(l10n.appTitle);
Text(l10n.retry);
Text(l10n.helloName('Ana'));
Text(l10n.itemsCount(3));
```

- `AppLocalizations.of(context)` is not nullable; the delegate is always
  installed through `AppLocalizationsConfig`.
- Placeholders and plurals are handled by gen-l10n/intl, not by a custom
  formatter.
- After changing an ARB file, run `flutter gen-l10n` or `flutter pub get`.

## Failure messages

`L10nFailureMessages` implements `FailureMessages` from `app_basic`. The module
registers it in the `Registry`, so `FailurePresenter.fromRegistry`
automatically uses text for the active locale. Unrecognized codes use
`failureUnexpected`.

## Language picker

```dart
LanguageSwitcher(
  controller: registry.read<LocaleController>(),
  config: registry.read<L10nConfig>(),
);
```

Use `style: LanguageSwitcherStyle.segmented` for the segmented look. The
language list comes from `supportedLocales`, not hardcoded in the widget.

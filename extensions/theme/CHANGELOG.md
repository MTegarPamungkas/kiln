# Changelog

## 0.2.0

- Removed `ThemeModeSwitcher`. The extension exposes theme data and the mode controller; applications render their own appearance controls.

## 0.1.1

- Add `ThemeConfig.validate` and `ThemeSupport` with seed, density, and
  preference-storage details.

## 0.1.0

- Light and dark brand themes from a seed, font, radius, and density.
- High-contrast color schemes, design tokens, and semantic colors.
- Persistent theme mode control through optional `Storage`.
- System, Light, and Dark mode picker widget.

# Changelog

## 0.1.0

- Menambahkan `LoggerModule` beserta `AppLogger`, konfigurasi level per flavor,
  dan kontrol level saat berjalan.
- Menambahkan sink pipeline, formatter teks dan JSON lines, penyamaran PII,
  buffer memori, berkas log berputar, dan breadcrumb crash.
- Menambahkan exporter log, middleware HTTP, serta halaman log debug.
